## License Compatibility Note

The bundled word lists are distributed under multiple licenses that are
not all mutually compatible if combined as a single derivative work.
For this reason, each word list is kept as a **separate data file**,
loaded at runtime by the generator. The generator's own source code is
distributed under its own license (see the `LICENSE` file at the root
of this project), and each word list file remains independently
governed by its original license as listed above.

This approach treats the word lists as separate aggregated works rather
than as a single combined work.
